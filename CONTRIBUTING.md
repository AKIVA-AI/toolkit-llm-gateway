# Contributing

## Quick Start

1. Create a feature branch.
2. Keep changes focused and add tests where applicable.
3. Run the test suite.
4. Open a PR with a clear description of behavior changes.

## Development

- Install (editable): `python -m pip install -e .[dev]`
- Tests: `pytest -q`

## Style

- Prefer small, reviewable PRs.
- Avoid introducing breaking changes without documenting migration steps.
